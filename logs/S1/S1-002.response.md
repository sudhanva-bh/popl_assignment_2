```scss
(define (inorder tree)
  (define (walk node acc)
    (if (null? node)
        acc
        (walk (cadr node)
              (cons (car node)
                    (walk (caddr node) acc)))))
  (walk tree '()))
```

### **How it works**

- **Base case:** An empty tree returns the accumulator `acc`.
- **Recursive case:** Process the right subtree, prepend the root value using `cons`, then process the left subtree.
- Although recursion evaluates the right subtree first, the resulting list is in **left → root → right** order.
- The initial accumulator is `()`, so an empty tree returns `()`.

**Complexity:**

- Time: \\(O(n)\\) — each node is visited once.
- Auxiliary space: \\(O(h)\\) recursion stack, excluding the \\(O(n)\\) output list, where \\(h\\) is the tree height.
- No repeated list copying, `append`, or forbidden built-ins.
