# P2 prompts

## P2-001

Can you help me plan P2 using the uploaded assignment? Break it into steps I can do one predicate at a time. Cover expression trees, exact division, canonical formatting, and collecting all equations. Flag any examples or edge cases worth checking early. Keep it to a short plan without code.

## P2-002

Can you write `split_numbers(List, Left, Right)` for P2? It should enumerate every split into two nonempty consecutive parts, once per cut position, while preserving the input order. It should fail for an empty or single-element list. Return the predicate definition.

## P2-003

Can you write `apply_operator(Op, Left, Right, Value)` for P2? `Left` and `Right` are integers and can be negative. Support `+`, `-`, `*`, and `/`, allowing division only when the divisor is nonzero and the result is exact. Let `Op` be given or enumerated on backtracking. Return the predicate clauses.

## P2-004

Can you write `expression(Numbers, Tree, Value)` for P2? Use `num(N)` for a leaf and `op(Op, LeftTree, RightTree)` for a binary expression. Use the existing `split_numbers/3` and `apply_operator/4` to generate all valid trees and integer values on backtracking, preserving the number order. Return the predicate clauses.

## P2-005

Can you write `precedence(Op, Level)` for P2? Give `+` and `-` level 1, and `*` and `/` level 2. Return the four facts.

## P2-006

Can you write `needs_parentheses(Side, ParentOp, ChildTree)` for P2? Use `precedence/2` and the existing `num(N)` and `op(Op, Left, Right)` tree shapes. A left operand needs parentheses when its precedence is lower than the parent’s. A right operand needs them when its precedence is equal or lower. A number never needs parentheses. Return the predicate clauses.

## P2-007

Can you write `format_expression(Tree, String)` for P2? Format `num(N)` as decimal digits and recursively format `op(Op, Left, Right)` using `needs_parentheses/3` for each operand. Return an SWI-Prolog string with no spaces. Return the predicate clauses.

## P2-008

Can you write `generate_equation(List, Equation)` for P2.a? Use `split_numbers/3`, `expression/3`, and `format_expression/2` to find two sides with the same integer value and join their strings with `=`. Leave valid equations available on backtracking so the next predicate can collect them. It should fail cleanly if none exist. Return the predicate definition.

## P2-009

Can you write `all_equations(List, Equations)` for P2.b? Collect the results from `generate_equation/2` with `findall/3`, then use `sort/2` to sort and remove duplicates. Return `[]` when there are no valid equations. Return the predicate definition.

## P2-010

Can you write `count_equations(List, N)` for P2.b? Use `all_equations/2` and return the length of its result, so the count matches the number of distinct equations. Return the predicate definition.
