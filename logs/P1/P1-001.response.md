### **Important checkpoints**

- **After step 9:** All eight original clues should work independently.
- **After step 13:** Establish the original solution count *before* introducing clue 9.
- **After step 15:** Clue 9 must leave exactly one solution and be written with a `% CLUE 9:` comment immediately above its clause.
- **After step 16:** Check exact output using `swipl -q -f id_q1.pl -g main -t halt`, with no extra text.

### **Where to start**

**Start with Step 1: the solution generator.**



It should generate complete, validly structured assignments without applying any clues yet. This gives every subsequent clue a consistent representation to work with.



Keep each step in the same P1 conversation with your external agent, save the prompts verbatim in `prompts/P1.md`, and commit incremental changes as you progress.
