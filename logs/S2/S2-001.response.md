Implement S2 in **6 small steps**, testing each function before moving on. The assignment requires incremental AI prompts and commits, so keep each implementation step separate.

1. **Implement&#x20;**`my-length`

   Recursively count only the top-level elements of a list.

   Test: `() → 0`, `(1 2 3) → 3`, `((1 2) (3)) → 2`.
2. **Implement&#x20;**`my-map`

   Apply a function to each top-level element, recursively constructing a new list with `cons`.

   Test with a simple function that increments numbers, including on an empty list.
3. **Implement the first&#x20;**`insert-if-short`
   - Recursively process nested lists using `my-map`.
   - Leave atoms unchanged using `pair?` and `null?` to distinguish list elements from atoms.
   - After processing children, use `my-length` on the **original list** to decide whether to prepend `x`.
   - Include the top-level list in this decision.

   Test all four official S2 examples before proceeding.
4. **Implement&#x20;**`make-inserter`

   Define `(make-inserter x len-ok?)` to return a function that processes a nested list.

   Replace the fixed comparison `(< (my-length lst) n)` with the supplied predicate `(len-ok? (my-length lst))`.

   Test independently using predicates such as length less than 3 and length equal to 2.
5. **Refactor&#x20;**`insert-if-short`

   Replace the original implementation with one that calls `make-inserter`, supplying a lambda that checks whether the length is less than `n`.

   Keep **only one definition** of `insert-if-short` in the final file. Rerun the original tests to ensure identical results.
6. **Implement&#x20;**`print-insert-result`

   Read `x`, `lst`, `n` in that order using `read`. Call `insert-if-short`, display the result, and print exactly one newline.

   Test through standard input, not just direct function calls.
