```sql
(define (inorder tree)
  (define (walk node k)
    (if (null? node)
        (k)
        (walk (cadr node)
              (lambda ()
                (cons (car node)
                      (walk (caddr node) k))))))
  (walk tree (lambda () '())))
```

### **How it works**

- **Empty tree:** Calls continuation `k`, ultimately returning `()`.
- **Left subtree:** Recursively visits the left subtree first.
- **Root:** Adds the current node's value using `cons`.
- **Right subtree:** Recursively visits the right subtree afterward.
- **Continuation (**`k`**):** Represents the remaining computation, allowing the list to be constructed without `append` or repeated copying.

**Complexity:** \\(O(n)\\) time, visiting each node once.



Uses only permitted Scheme forms and respects left-before-right traversal order.
